# 🇹🇼 台灣房地產實價登錄爬蟲、歷史資料庫與地圖可視化系統
Taiwan Real Estate Assessment & Intelligence Platform

本專案針對**台灣內政部不動產交易實價登錄平台 (plvr.land.moi.gov.tw)** 特有架構設計，提供全自動化爬蟲、歷史資料庫回溯、資料標準化清洗、空間行政區映射，以及互動式地圖視覺化儀表板。

---

## 🌟 核心特色與架構解析

### 1. 應對台灣實價登錄特有架構之設計
* **雙表頭與 UTF-8-BOM 解析**: 內政部 CSV 檔第 1 行為中文欄位名稱、第 2 行為英文說明，自第 3 行起為實際資料。爬蟲自動過濾雙表頭並處理編碼問題。
* **民國年 (ROC Year) 自動轉換**: 系統自動將 `1010815` 或 `1131102` 等民國年月日格式轉換為標準 ISO 西元日期 `YYYY-MM-DD`，並精確拆解西元年份、季度 (`YYYYQ#`) 與月份。
* **坪數與單價慣用標準化**:
  * 台灣房地產交易慣用「**坪**」為單位（$1\text{ 平方公尺} = 0.3025\text{ 坪}$）。
  * 系統自動計算：建物移轉總坪數、土地移轉坪數、車位坪數。
  * 自動換算每坪單價（**萬元/坪**）與成交總價（**萬元**），補齊或校正未填寫單價之建坪案件。
* **縣市代碼對應**:
  * MOI Open Data 檔名以台灣身分證代碼命名（`A`: 臺北市、`B`: 臺中市、`C`: 基隆市、`D`: 臺南市、`E`: 高雄市、`F`: 新北市 ... 全台 22 縣市）。
  * 自動將檔名代碼與鄉鎮市區拼合為完整行政區識別碼（如 `臺北市大安區`、`新北市板橋區`）。
* **特殊關係人與異常交易過濾**:
  * 實價登錄之「備註」欄常包含親友交易、員工價、持分移轉、法拍、急買急賣等非典型市場交易。
  * 系統內建關鍵字篩選器，預設自動標記並排除特殊交易，確保行情統計客觀真實。

## 📈 三大可視化與分析維度

1. **成交量與其變化 (Volume & Liquidity)**
   * 各縣市與各鄉鎮市區當季成交總筆數。
   * 季變動率（**QoQ %**）與年增率（**YoY %**），即時呈現房市量能擴張或量縮觀望。
2. **交易金額與其變化 (Price Trends & GMV)**
   * 平均每坪單價（**萬元/坪**）與中位數每坪單價。
   * 歷年價格季漲跌幅（**QoQ %**）與年漲跌幅（**YoY %**）。
   * 當期總交易金額（**億元**）。
3. **市場熱度分析 (Composite Market Heat Index)**
   * 整合**量能動能 (35%)**、**價格動能 (35%)** 與**流動性活躍度 (30%)** 之綜合評分模型（0 - 100 分）：
     * 🔥 **爆發熱絡 (75+ 分)**: 量價齊揚，買氣追價強勁。
     * 📈 **穩健成長 (58-74 分)**: 交易熱絡，房價穩定上升。
     * ⚖️ **盤整持平 (42-57 分)**: 量價平衡，微幅波動。
     * ❄️ **冷卻觀望 (< 42 分)**: 交易量縮，流動性偏弱。
   * 全國與各縣市 Top 10 熱區排行榜。

## 🗺️ 台灣地圖可視化儀表板 (Interactive Map)

* **現代化地圖視覺化**: 基於 Leaflet.js 與 CartoDB 深色底圖，搭配自定義 Choropleth 色階。
* **雙層級切換**: 支援「全台縣市 (22)」與「鄉鎮市區 (382)」邊界即時著色。
* **時間軸演變與動態播放 (Time Slider & Auto-Play)**: 拖曳滑桿或點擊播放按鈕，動態觀看台灣房市歷年變遷。
* **互動聯動 (Drill-down)**:
  * 懸停地圖區塊即時顯示詳細量價 Tooltip。
  * 點擊任一行政區，自動放大並在右側面板繪製該區「歷年量價雙軸走勢圖 (Chart.js)」。

## 🚀 快速開始使用

### 1. 安裝環境需求
Python 3.10+，核心套件包含 `fastapi`, `uvicorn`, `pandas`, `requests`（已就緒）。

### 2. 統一 CLI 指令

#### (1) 撈取最新發布資料
```bash
python main.py crawl-latest
```
自動向內政部下載本期發布之最新批次（每月 1、11、21 日固定更新），自動解析入庫並重算最新聚合數據。

#### (2) 回溯補齊歷史資料
```bash
# 從 101S3 (實價登錄起始) 一路補齊至最新
python main.py backfill --start 101S3

# 指定補齊特定年份區間
python main.py backfill --start 101S3 --end 105S4
```
具備**斷點續傳機制 (Checkpoint)**，已處理過的季度會自動跳過，支援失敗重試與速率保護。

#### (3) 重新計算統計聚合與熱度
```bash
python main.py aggregate
```

#### (4) 啟動可視化儀表板 Web 伺服器
```bash
python main.py serve --port 8000
```
開啟瀏覽器前往：`http://localhost:8000` 即可進入互動式儀表板！

    └── style.css           # 深色主題樣式與動畫
